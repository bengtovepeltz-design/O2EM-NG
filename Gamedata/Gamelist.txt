bios = internal ROM of the microprocessor
br   = Brazilian game
im   = Imagic
jo   = Jopac
mod  = modified game (by me)
new  = new game
ntsc = NTSC version for American consoles (made by me)
o2   = Odyssey2 game, only the Odyssey2 games that are different
       from the Videopac version are present
pal  = PAL version for European consoles (made by me)
pb   = Parker Brothers
pr   = prototype game, never released
vp   = Videopac

..._pl = Plus (+) version, extra background graphics on a G7400 (or Odyssey3)
..._12 or ..._16 = 12k or 16k game, cartridge has extra chips
..._F  = french version
...alt = alternate version
...hack = modified by someone else
...fix = bug fixed
