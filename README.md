# O2EM-NG

A Windows x64, SDL3-based continuation of the original O2EM emulator for
Philips Videopac G7000 / G7400 and Magnavox Odyssey².

**Current release: O2EM-NG Beta 5 v5.0.2 — Licensing & Attribution Update.**

This release updates copyright notices, licensing documentation, source
provenance, attribution and credits. It does not change the NG emulation
engines.
