Optional

Place your own Manuals in this folder.

The box art filename must match the ROM filename (without the file extension).

Example:

ROMS
    Gunfighter.bin

BOXART
    Gunfighter.jpg
or
    Gunfighter.png
	
MANUALS
	Gunfighter.pdf

Supported image formats:

- *.jpg
- *.png

If no matching box art is found, O2EM-NG will display the default artwork.
