O2EM-NG Patch 0014b
====================

Apply this patch on top of Patch 0014a.

Changes:
- Fullscreen setting now applies immediately without restarting O2EM-NG.
- Window position and size are remembered when entering fullscreen and restored when leaving it.
- Header artwork is shown completely in both windowed and fullscreen modes instead of being heavily cropped.
- Added a clickable EXIT button in the bottom-right status bar.
- Xbox B / Escape behaviour remains unchanged.

After extracting over the project root, run Rebuild Solution.
