MAME 0.289 runtime differential fixture
=======================================

Machine: videopac (Philips Videopac G7000, PAL)
Cartridge: tests/machine_ng/fixtures/synth_std_2k.bin
Commands:
  mame videopac -rompath <mame>/roms -cart <synth_std_2k.bin> \
       -debug -debugger windows -debugscript trace.cmd
  trace.cmd: trace <file>,:maincpu,noloop ; gtime 50 ; trace off ; traceflush ; quit

The fixture program is synthetic project data. It exercises:
  DIS I / DIS TCNTI
  P1 decode, external RAM MOVX writes and reads
  ANL/ADD/ADDC/XRL/ORL/CPL/SWAP/RL/RLC/RR/RRC/DA
  XCH/XCHD
  VDC A0/A3/05 writes, V0 read
  cartridge I/O window
  INS A,BUS / OUTL BUS / OUTL P2 / IN A,P2 / IN A,P1
  timer MOV T,A / STRT T / MOV A,T / STOP TCNT
  DJNZ loop and final JMP loop

The IRQ phase difference after that point is the VDC VBL timer phase, not a
CPU or bus semantic difference. MAME schedules the i8245 VBL timer with
screen().time_until_pos(vblank_start, hblank_start - 1); screen_device
measures scanlines relative to VBLANK, so the absolute line is
vblank_start + (vtotal - visible_h) = 312 on PAL and 262 on NTSC. NG-2 uses
that exact absolute line (see timebase.h, VblankIrqOffset).

Comparison scope note:
  MAME 0.289's debugger exposes PC/A/R0-R7/P1/P2/TC/TPRE/SP/EA in
  this setup. PSW and internal IRQ latches are not exposed as debugger
  symbols. NG-2 therefore compares the full instruction stream, A, all
  registers, ports, timer/prescaler, SP and bank selection against MAME,
  and covers PSW/IRQ/held-line semantics with its own deterministic tests.
