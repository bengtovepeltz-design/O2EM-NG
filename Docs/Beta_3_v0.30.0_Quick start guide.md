# O2EM-NG Quick Start Guide

Welcome to **O2EM-NG**!

## Installation

1. Install O2EM-NG or extract the portable ZIP.
2. Copy your legally owned BIOS file into the **BIOS** folder.

Examples:

```text
BIOS/G7000.bin
BIOS/G7400.bin
BIOS/Odyssey2.bin
```

Use the BIOS filename that matches the console you want to emulate.

3. Copy your game ROMs into the **ROMS** folder.

## Optional

Use the **Import Center** to add:

- Box Art
- Manuals (PDF)
- Screenshots

## First Start

Launch **O2EM-NG**.

The program automatically creates its local game database on first start, and your games will appear in the **Game Library**.

## Controls

### Frontend

- Enter / A – Select
- Esc / B – Back

### In Game

- F5 – Reset
- Esc – Return to Game Library
- Xbox Y – Swap controller ports
